# Provenance

This repository is a snapshot of the work, published as a single commit. The full development history is in the
archived repository [martinbon39/ComputerUseHackaton](https://github.com/martinbon39/ComputerUseHackaton) (read-only).
Every commit hash cited in this repository, in the paper's source comments or in a data file refers to that repository.
Its history carries the timing evidence the paper relies on: when each pre-registration, protocol and amendment was
committed, and that analysis code was committed before the results it analyses were read.

A commit time proves only that a file existed at that time. Whether it came before the data it judges is stated in the
file itself and in the paper's appendix "How the research was run"; the result files say what had been seen when each
amendment was written. Pre-registration, protocol and amendment files are byte-identical to their last version in the development
repository (commit [`26565da`](https://github.com/martinbon39/ComputerUseHackaton/commit/26565dace87c55db3f1ce69cfe4dead6ba1472a6)), so they
can be compared directly; reports differ only in updated paths, and data files are byte-identical. Times are committer times, UTC. Paths are those of this repository; the former paths are in
[REPO_MAP.md](REPO_MAP.md).
